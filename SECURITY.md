# Security policy

Pocket Deck Lab is a static site with no server, accounts or stored secrets. It reads only data you give
it (decklists, deck codes, screenshots) and processes them in your browser.

If you find a vulnerability (for example, a crafted deck code, share link or image that runs script, or
corrupts or leaks local data), please **report it privately** through
[GitHub Security Advisories](https://github.com/calerio/pokemon-tcg-pocket-deck-builder/security/advisories/new)
rather than opening a public issue. Expect an acknowledgement within a week.

Supported version: the latest deployment on `main`.
